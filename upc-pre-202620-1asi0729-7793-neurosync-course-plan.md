# Fundamentos de Java para Principiantes

## Resumen del Curso

Curso gratuito de introducción a Java para estudiantes de 12 a 17 años, sin conocimientos previos. Duración de los videos: 60 minutos en seis lecciones. Las prácticas se realizan en el navegador, sin instalar programas. El tiempo de práctica con el video pausado es adicional.

Repositorio de código: [Open-SourceHelper/java-fundamentals-course-neurosync](https://github.com/Open-SourceHelper/java-fundamentals-course-neurosync).

## Secuencia de la Lección

### Lección 1: ¿Qué es Java y la Programación? (5 minutos)

- **Descripción**: Aprende qué es la programación y por qué Java es un excelente lenguaje para empezar.
- **Enlace**: [Ver video en YouTube](https://youtu.be/Y8xFMt5QvDI)
- **Conclusiones clave**: Java se usa para aplicaciones y juegos; los programas son instrucciones para computadoras.
- **Empieza a programar**: Hola mundo en Replit. Ejercicio precargado pendiente. Editor: https://replit.com/.

### Lección 2: Variables y tipos de datos (8 minutos)

- **Descripción**: Aprende a almacenar datos en Java usando variables.
- **Enlace**: [Ver video en YouTube](https://youtu.be/2nKUMU2LkhE)
- **Conclusiones clave**: Usa int, String; declara como int age = 15;
- **Práctica**: Variables en Replit. Ejercicio precargado pendiente. Editor: https://replit.com/.

### Lección 3: Estructuras de control: Decisiones y bucles (10 minutos)

- **Descripción**: Toma decisiones con if-else y repite tareas con bucles.
- **Enlace**: Pendiente
- **Conclusiones clave**: if (age > 12) {}; for (int i=0; i<5; i++) {}
- **Práctica**: Decisiones y bucles en JDoodle. Ejercicio precargado pendiente. Editor: https://www.jdoodle.com/online-java-compiler.

### Lección 4: Métodos, Entrada/Salida e Introducción a la POO (12 minutos)

- **Descripción**: Crea código reutilizable con métodos, obtén la entrada del usuario e introduce clases/objetos.
- **Enlace**: PENDIENTE — video de YouTube No listado.
- **Conclusiones clave**: public static void greet() {}; Use Scanner; class Pet { String name; }
- **Práctica**: Métodos, entrada y objetos en OnlineGDB. Ejercicio precargado pendiente. Editor: https://www.onlinegdb.com/online_java_compiler.

### Lección 5: Fundamentos de POO y programas sencillos (15 minutos)

- **Descripción**: Construye clases con atributos/métodos y crea un programa POO básico.
- **Enlace**: PENDIENTE — video de YouTube No listado.
- **Conclusiones clave**: Encapsulación con getters; Construye un simulador de "mascotas".
- **Proyecto final**: Aplicación POO de mascotas en Replit. Ejercicio precargado pendiente. Editor: https://replit.com/.

### Lección 6: Consejos y próximos pasos (10 minutos)

- **Descripción**: Mejores prácticas, errores comunes y dónde aprender más.
- **Enlace**: [Ver video en YouTube](https://youtu.be/YZpjWOAo50Y)
- **Consejos clave**: Depurar errores, explorar la documentación de Oracle Java.
- **Compartir tu trabajo**: Cuestionario incluido en scripts/leccion-06/cuestionario.md y actividad para compartir. Enlace al formulario o canal: PENDIENTE.
