# Fundamentos de Java para principiantes

Curso de 60 minutos para estudiantes de 12 a 17 años sin experiencia previa. Cada lección usa Java en el navegador. No es necesario instalar Java ni descargar herramientas.

Consulta el [plan del curso](upc-pre-202620-1asi0729-7793-neurosync-course-plan.md) para ver los objetivos, los recursos y la elaboración del trabajo.

## Cómo practicar

1. Abre el editor en línea indicado para la lección.
2. Copia en `Main.java` el código inicial de `starter-files/leccion-XX/`.
3. Ejecuta, resuelve la práctica y compara con `completed-examples/` y `practice-solutions/`.

Cada carpeta de `scripts/` contiene un índice de la lección, el guion, las diapositivas y la práctica. Los tiempos son los del plan. Los enlaces de los editores son accesos generales; los ejercicios precargados se registrarán cuando se publiquen. Los videos 4 y 5 aún no tienen enlace. No se ha comprobado la visibilidad de los videos.
